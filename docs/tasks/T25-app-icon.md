# T25 · App icon

Phase 5 · Target: tools + Resources · Risk: low · Detail: outline

## Goal

Aash has an app icon made from the idle sprite (for Finder, About and Login Items), generated by a
script so it always matches the sprite.

## Read first

- `docs/sprites.md`

## Files (expected)

- create `tools/make-icon.swift` (renders the idle frame onto a rounded square at every iconset size)
- create `Resources/AppIcon.icns` (made with `iconutil -c icns`)
- edit `Resources/Info.plist` (`CFBundleIconFile` = `AppIcon`); `scripts/build.sh` already copies
  `Resources/AppIcon.icns`

## Done when (to be detailed by /plan-phase 5)

- [ ] `./scripts/check.sh` prints `CHECK PASS`
- [ ] Manual: About Aash shows the icon; so does `~/Applications` after `./scripts/install.sh`
